LineBuilder

Assemble a semiconductor & photonics cleanroom process line, step by step, and get its cradle-to-gate carbon footprint — computed locally on your own machine.

★ View on GitHub Install guide

What it does

Pick a wafer, load a standard flow or add steps one by one, choose your electricity grid — and see the GWP, broken down by step.

29 process templates

Lithography, etch, cleaning, deposition (MOCVD / ALD / PECVD / PVD), doping, thermal, bonding, dicing and more — each fully parameterised.

Real wafer formats

Si, SOI, InP and Ge in their actual SEMI diameters and coupled thicknesses. No impossible substrates.

Grid & voltage

Switch the electricity supply across 11 regions and MV/HV — the single biggest lever in a cleanroom line.

Auditable

Every run is a real Brightway inventory you can open in Activity Browser and export to Excel. No black box.

10 standard flows

Litho blocks, pattern transfer, doping, metallisation lift-off, wafer bonding and the integration routes — one click.

Custom material chains

Bundled foreground datasets for the III-V and Ge chains, precursors and sputter targets that ecoinvent lacks.

How it works

It runs entirely on your computer — nothing is uploaded. GitHub only hosts the code.

You bring ecoinvent

Supply your own licensed ecoinvent 3.12 cutoff. It is never shipped here — the tool only references it.

Set up the project once

setup_project.py builds a Brightway project and imports the bundled dataset library, then verifies every link.

Run & compute

python app.py → open your browser → build a line → get the footprint and the per-step hotspots.

Get started

Full details in the README.

git clone https://github.com/lehen31/linebuilder-lca.git
cd linebuilder-lca
conda env create -f environment.yml
conda activate linebuilder
python setup_project.py --project LineBuilder --ecoinvent "PATH\to\ecoinvent\datasets"
python app.py        # then open http://127.0.0.1:5000

Requires: conda (Python) and your own ecoinvent 3.12 cutoff license. Already run Activity Browser with ecoinvent imported? Point --project at that project and skip the ecoinvent import.
